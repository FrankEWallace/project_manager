## What is an actor?

An **actor** is anyone or any organisation involved in your work. There are four types:

| Type | Use for |
|---|---|
| `Client` | The person or company you're delivering work to |
| `Collaborator` | Freelancers, contractors, co-founders |
| `Vendor` | Software subscriptions, services, suppliers |
| `Advisor` | Mentors, consultants, investors |

Actors are workspace-level — you create them once and can link them to many projects.

---

## Creating an actor

1. Navigate to **Actors** in the sidebar.
2. Click **Add actor**.
3. Fill in:
   - **Name** — required
   - **Type** — Client / Collaborator / Vendor / Advisor
   - **Email** — optional but useful for filtering
   - **Company** — optional
   - **Notes** — free text for context
4. Click **Save**.

---

## Linking an actor to a project

1. Open a project.
2. Go to the **Actors** tab on the project.
3. Click **Link actor** and search by name or email.
4. Select the actor — they're now associated with the project.

One actor can be linked to multiple projects. Removing the link from a project does **not** delete the actor from your workspace.

---

## Actor table view

The main Actors page shows a table of all actors in your workspace. You can:
- **Filter** by type (Client, Collaborator, etc.)
- **Search** by name or email
- **Click a row** to open the actor detail and see which projects they're linked to

---

## Deleting an actor

Open the actor detail view, click the ⋯ menu, and select **Delete actor**.

<Warning>
Deleting an actor removes them from all project links. This cannot be undone.
</Warning>
